# Лабораторна робота 17 — слайдер на React

Слайдер відгуків із переходом між слайдами, автоматичною прокруткою та випадковим вибором відгуку.

## Запуск

```bash
npm install
npm start
```

Для production-збірки виконайте `npm run build`.

## Як працює автопрокрутка

`useEffect` створює таймер `setInterval`, який кожні дві секунди перемикає активний слайд. Залежність `[index]` змушує ефект перезапуститися після зміни поточного слайда, щоб таймер працював з актуальним значенням `index`.

`clearInterval` у функції очищення зупиняє попередній таймер перед повторним запуском ефекту та при видаленні компонента. Без очищення старі інтервали продовжували б працювати паралельно, спричиняючи зайві оновлення та витік ресурсів.
